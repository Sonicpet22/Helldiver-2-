# Helldivers 2

ข้อมูลอาวุธและศัตรูในเกม

## อาวุธ

จัดตามช่องที่พกได้ก่อนลงภารกิจ

| ช่อง | จำนวน | ใช้ตอนไหน |
| --- | ---: | --- |
| อาวุธหลัก | 55 | ปืนหลักที่ถือออกจากเฮลพอด |
| อาวุธรอง | 25 | ปืนพก อาวุธประชิด และอาวุธพิเศษ |
| อาวุธขว้าง | 23 | ระเบิดและกับดักมือ |
| อาวุธสนับสนุน | 35 | เรียกจากสตราทาเจมระหว่างภารกิจ |

ชุดเริ่มต้นของทุกคนคือ **AR-23 Liberator**, **P-2 Peacemaker** และ **G-12 High Explosive**

ตารางดาเมจ ระดับเจาะเกราะ อัตรายิง และวิธีปลดล็อกอยู่ที่ [WEAPONS.md](WEAPONS.md)  
ข้อมูลชุดเดียวกันในรูปแบบ JSON อยู่ที่ [data/weapons.json](data/weapons.json)

## ศัตรู

หน่วยศัตรู 87 หน่วยจาก 3 ฝ่ายหลัก บวกหน่วยฝ่ายเดียวกันที่โดนลูกหลงได้

| ฝ่าย | จำนวนหน่วย | จุดเด่น |
| --- | ---: | --- |
| เทอร์มินิด (แมลง) | 30 | รุมเข้าประชิด พ่นกรด มีสายพันธุ์ Predator, Spore Burst, Rupture |
| ออโตมาตอน (หุ่นยนต์) | 37 | ทหารราบหุ้มเกราะและยานรบ มีหน่วยย่อย Jet Brigade, Incineration Corps, Cyborg Legion |
| อิลลูมิเนต (หมึก) | 16 | โล่พลังงาน พลาสมา โดรน มีหน่วยย่อย Appropriators, Vote Snatchers |
| ซูเปอร์เอิร์ธ | 4 | พลเมือง ทหาร SEAF และ Helldiver ด้วยกัน |

ตารางพลังชีวิต ขนาด ดาเมจที่ทำใส่เรา และความยากต่ำสุดที่เจออยู่ที่ [ENEMIES.md](ENEMIES.md)  
ข้อมูลชุดเดียวกันในรูปแบบ JSON อยู่ที่ [data/enemies.json](data/enemies.json)
