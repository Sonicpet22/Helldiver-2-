# Helldivers 2

ข้อมูลอาวุธในเกม สรุปจากไฟล์สถิติของ [Helldivers Wiki](https://helldivers.wiki.gg/wiki/Weapons) อ้างอิงแพตช์ 1.007.100 (ดึงข้อมูล 5 ตุลาคม 2026)

ก่อนออกภารกิจต้องเลือกอาวุธหลัก 1 ชิ้น อาวุธรอง 1 ชิ้น และอาวุธขว้าง 1 ชิ้น อาวุธสนับสนุนเรียกจากสแตรทาเจมระหว่างภารกิจ

| ช่อง | จำนวนในชุดข้อมูล |
| --- | --- |
| อาวุธหลัก | 55 |
| อาวุธรอง | 24 |
| อาวุธขว้าง | 23 |
| อาวุธสนับสนุน | 34 |

ตารางเต็มอยู่ที่ [docs/weapons.md](docs/weapons.md) ข้อมูลโครงสร้างอยู่ที่ [data/weapons.json](data/weapons.json)

## เจาะเกราะ

ทุกชิ้นส่วนของศัตรูมีค่าระดับเกราะ อาวุธมีค่าเจาะเกราะเป็นเลขชุดเดียวกัน

| ค่า | ระดับ |
| --- | --- |
| 0 | ไม่มีเกราะ |
| 1 | บางมาก |
| 2 | เบา |
| 3 | กลาง |
| 4 | หนัก |
| 5 | ต่อต้านรถถัง I |
| 6 | ต่อต้านรถถัง II |
| 7 | ต่อต้านรถถัง III |

- เจาะเกราะสูงกว่าระดับเกราะของชิ้นส่วน: ดาเมจ 100%
- เท่ากัน: ดาเมจ 65%
- ต่ำกว่า: กระสุนสะท้อน และไม่ทำดาเมจ

ดาเมจในตารางเป็นดาเมจตรงต่อนัด ดาเมจส่วนทนทานใช้กับชิ้นส่วนที่ทนทาน เช่น ตัวถังหรือถุงน้ำดี อาวุธระเบิดมักทำดาเมจส่วนทนทานได้เต็มจำนวน

## ชุดเริ่มต้น

| อาวุธ | ดาเมจ | ส่วนทนทาน | เจาะเกราะ | บรรจุ | นัด/นาที |
| --- | --- | --- | --- | --- | --- |
| AR-23 Liberator | 90 | 22 | เบา (2) | 45 + 8 แม็ก | 640 |
| P-2 Peacemaker | 100 | 32 | เบา (2) | 15 + 8 แม็ก | 900 |
| G-12 High Explosive | 800 | 800 | หนัก (4) | พก 5 | — |

Liberator ยิงศัตรูไม่มีเกราะและเกราะบางได้เต็มดาเมจ แต่สะท้อนจากเกราะกลางขึ้นไป ต้องเล็งจุดอ่อน หรือพกอาวุธที่เจาะกลางขึ้นไปเป็นอาวุธรองหรืออาวุธสนับสนุน

## ข้อจำกัดของชุดข้อมูล

- ตัวเลขเปลี่ยนตามแพตช์ ถ้าเกมใหม่กว่า 1.007.100 ให้ยึดค่าในเกมหรือวิกิเป็นหลัก
- ปืนลูกซองแสดงเป็นดาเมจต่อเม็ดคูณจำนวนเม็ด เช่น Punisher คือ 45×9
- อาวุธพ่นไฟเก็บดาเมจเป็นต่ออนุภาค จึงดูต่ำกว่าดาเมจต่อนัดของปืนทั่วไป
- อาวุธที่มีหลายโหมดยิงใช้โหมดที่เจาะเกราะสูงสุดเป็นแถวหลัก โหมดที่เหลืออยู่ในคอลัมน์หมายเหตุ
- CQC-73 Entrenchment Tool และ MS-11 Solo Silo มีชื่อในสารบัญวิกิ แต่ไม่มีแถวในไฟล์สถิติที่ใช้นี้
- โดรน Guard Dog, โล่ และเป้ไม่ได้อยู่ในรายการอาวุธ
